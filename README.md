# FF7 Round-Based Battle System (Godot)
This project is a turn-based battle game inspired by Final Fantasy VII, developed using the Godot game engine. It focuses on recreating the classic JRPG combat experience, including:
  ▪️Round-based battle flow
  ▪️Character selection and turn order system
  ▪️Skill usage and damage calculation
  ▪️Basic animations for attack and idle states
  ▪️Win/lose conditions and battle transitions
The project is designed as a learning and demonstration of game development using Godot, especially for implementing RPG-style battle systems.
